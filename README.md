# EdTech User Engagement & Learning Behavior Analysis

## Project Overview

This project analyzes user behavior on an EdTech platform to understand how learners interact with the platform and what factors are associated with engagement, course completion and user satisfaction.

The analysis focuses on transforming user-level data into meaningful business insights that can help an EdTech company improve learner engagement, course completion and the overall learning experience.

## Business Objective

The objective of this project is to analyze learning platform usage patterns and identify factors that influence:

- User engagement
- Learning activity
- Course completion
- User satisfaction
- Platform usage behavior

The insights generated from the analysis can support business teams in making data-driven decisions related to learner experience and platform improvement.

## Business Problem

An EdTech platform serves users with different backgrounds, learning behaviors and usage patterns.

The business needs to understand:

- Which users are most engaged with the platform?
- How does learning activity relate to course completion?
- Which user segments demonstrate stronger completion behavior?
- Does learning purpose influence completion?
- What factors are associated with higher user satisfaction?
- How do platform and device usage differ across users?

Understanding these patterns can help the business identify opportunities to improve engagement and learning outcomes.

## Analysis Areas

The project covers the following major analytical areas:

### 1. User & Dataset Analysis

- Understanding the structure of the dataset
- Examining user attributes
- Identifying important behavioral variables
- Checking data types and data quality

### 2. User Engagement Analysis

Analyzed user engagement patterns including:

- Learning hours
- User groups
- Platform usage
- Device usage
- Learning behavior

### 3. Course Completion Analysis

Explored patterns related to:

- Course completion rates
- User engagement
- Learning purpose
- Different user segments
- Potential drop-off behavior

### 4. User Satisfaction Analysis

Analyzed satisfaction patterns across:

- User groups
- Completion behavior
- Platform usage
- Device usage

### 5. Exploratory Data Analysis

Used descriptive analysis and visualizations to identify patterns and relationships within the data.

## Key Business Questions

The analysis aims to answer questions such as:

1. Which user groups are the most engaged?
2. How does learning time relate to course completion?
3. Which segments have higher completion rates?
4. Does learning purpose influence completion behavior?
5. What patterns are associated with user satisfaction?
6. How does platform or device usage vary among learners?

## Visual Analysis

The project includes visual analysis covering:

- User engagement distribution

- Satisfaction analysis
- Platform usage patterns

The visualizations are designed to communicate business findings rather than simply display data.

##   Business Insights

The analysis helps identify important patterns in:

- Learner engagement
- Learning activity
- Course completion
- User satisfaction
- Platform and device usage

These insights can help the business understand learner behavior and identify areas where the platform experience can be improved.

## Business Recommendations

Based on the analysis, potential business actions include:

- Develop targeted engagement strategies for less-active users.
- Provide additional support to users showing signs of low completion.
- Improve learning experiences for different user segments.
- Optimize platform features based on usage behavior.
- Use satisfaction and engagement data to continuously improve the learner experience.
